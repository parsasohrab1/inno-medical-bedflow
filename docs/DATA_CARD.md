# کارت داده — inno-medical-bedflow

- **منبع:** کاملاً مصنوعی؛ تولید با `python -m inno_medical_bedflow generate --seed N` (قطعی). هیچ داده‌ی بیمار، شخص یا مرکز واقعی در ریپو نیست.
- **نمونه‌ی ذخیره‌شده:** `data/sample/*.csv` (seed=0).
- **فرض‌ها:** ۴ بخش، ۴۰۰ روز؛ مدت اقامت لوگ‌نرمال؛ پرچم «آماده‌ی ترخیص» در شبیه‌سازی برای فهرست ترخیص ساخته شده و معیار اعتبار نیست (فقط تست واحد).
- **استفاده‌ی مجاز:** توسعه و آزمون نرم‌افزار. استفاده برای آموزش/ارزیابی مدل بالینی یا هر تصمیم واقعی مجاز نیست.
- **حریم خصوصی:** هنگام ورود داده‌ی واقعی باید بی‌نام‌سازی، مجوز اخلاق و توافق‌نامه‌ی اشتراک داده انجام شود.
